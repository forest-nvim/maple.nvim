# maple.nvim

A minimal note taking plugin for neovim. one note per project, and a global note. Useful for writing quick notes, todos, etc.

> note that the stuff below was generated by claude. I dont care enough to write a readme this detailed. You can rest assured that the code was written by me

Project notes are keyed by git root (or cwd) and live under `stdpath("data")/maple`,
mirroring the project path. They are ordinary files: `:w`, undo history, swap recovery and
your markdown plugins all work. A note is also written whenever you leave its buffer.

Requires Neovim 0.10+.

## Install

```lua
-- lazy.nvim
{ "forest-nvim/maple.nvim" }
```

`setup()` is optional.

## Use

```
:Maple [global|project] [float|split|vsplit|edit]
```

Words go in any order. Defaults are `project` and `float`. Running it again for the note
that is open closes it; running it for the other note swaps to it. `q` closes a float.

```lua
vim.keymap.set("n", "<leader>m", "<cmd>Maple<cr>")
vim.keymap.set("n", "<leader>M", "<cmd>Maple global<cr>")
```

From Lua: `require("maple").toggle(scope, how)`, `.open(scope, how)`, `.close()` and
`.path(scope)`.

## Configure

```lua
require("maple").setup({
	dir = vim.fn.stdpath("data") .. "/maple",
	root = function()
		return vim.fs.root(vim.fn.getcwd(), ".git") or vim.fn.getcwd()
	end,
	float = { width = 0.6, height = 0.6, border = "rounded" }, -- merged into nvim_open_win
})
```

Anything `nvim_open_win` accepts goes in `float`, for example `title = " maple "` or
`style = "minimal"`.

## Adding things back

Notes are plain files in one directory, so most features are a line in your config.

Search across notes with whatever picker you use:

```lua
require("telescope.builtin").live_grep({ cwd = require("maple").config.dir })
```

Window options for notes, such as `winblend` or `relativenumber`:

```lua
vim.api.nvim_create_autocmd("BufWinEnter", {
	pattern = require("maple").config.dir .. "/*",
	callback = function()
		vim.wo.winblend = 10
	end,
})
```
